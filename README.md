# NutriQuiz 🥦🎮

Jogo educacional 2D mobile sobre alimentação saudável, desenvolvido para crianças com seletividade alimentar. O jogador responde adivinhas sobre alimentos para ganhar pontuação

## 🎯 Objetivo Pedagógico

Estimular o reconhecimento e a aceitação de alimentos saudáveis em crianças por meio de mecânicas lúdicas e narrativa envolvente, desenvolvido em parceria com profissional de nutrição.

## 🛠️ Tecnologias

- Unity 6
- C#
- TextMeshPro

## 📌 Como rodar o projeto
1. Baixe o projeto
2. Abra na Unity Hub
3. Execute a cena principal
